# Wei 的拍賣小舖

公司拍賣會的商品頁。品項和價錢放在 Google 試算表，照片放在這個 repo 的 `images/`。

## 平常怎麼維護

- **新增商品、改價錢、改狀態**：改 Google 試算表的「商品」分頁，幾分鐘內網頁會更新。
- **銅板價籃子**：改試算表的「籃子」分頁。
- **照片**：檔名對應商品編號，放進 `images/`。編號 1 是 `001.jpg`，同一件的第二張是 `001-2.jpg`，最多 6 張。沒有照片的商品會顯示分類圖示。
- **玉山帳號、預訂表單連結**：改 `config.js`。

## 壓縮照片

```bash
pip install pillow
python3 tools/resize.py <照片資料夾>
```

照片檔名先改成商品編號（例如 `1.jpg`、`12-2.png`），script 會縮到長邊 1200px 並輸出到 `images/`。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 頁面與樣式 |
| `app.js` | 讀試算表、畫卡片、篩選 |
| `config.js` | 試算表 ID、銀行帳號、預訂表單連結 |
| `images/` | 商品照片 |
| `tools/resize.py` | 照片壓縮 |
